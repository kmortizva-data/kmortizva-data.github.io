Concentra

Turns the public syllabus of a course into a study sheet you can actually consult later.

The problem
You finish an online course and three weeks later you have the certificate and none of the content. Notes taken while watching are not notes anyone can consult.
How I solved it
The module map is generated from the syllabus, never typed by hand. Around it I write the glossary, the recipe, the pitfalls and the review questions, with analogies from metallurgy.
The result
A sheet per module that still works a year later: a worked example before the theory, code explained line by line with its real output, and the traps written down.

Measured

23 rounds of correction for the first course alone

Course 3 took 23 passes before it was right. The procedure that came out of that is written down in MANUAL.md, and three automated checks now have to pass before anything is committed. Skipping it means doing the work three times.

I pay for courses, watch them and forget them. There was nowhere to look things up afterwards in a condensed form, so I built one.

These are my own notes, rewritten from scratch after each module: a worked example before the theory, the code explained line by line with its real output, and the traps I fell into. I hope they are useful to someone else.

The site itself has no dependencies at all, just the Python standard library, which means it still builds on a machine where installing anything is slow.
