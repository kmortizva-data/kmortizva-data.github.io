# datageeksunited.com

The source of my portfolio. Static HTML, two languages, generated by a script that uses
nothing but the Python standard library.

## Build

```
python src/build.py
```

That writes `index.html`, `es/index.html` and a page per project, copies the stylesheet and
the note PDFs, and writes `CNAME`. To read it before publishing:

```
python -m http.server 8790
```

## What to edit

| Path | What it is |
|---|---|
| `content/site.json` | **every string on the site, in both languages** |
| `templates/style.css` | the design |
| `templates/theme.js` | theme toggle and scroll reveal |
| `src/build.py` | the generator |
| `assets/shots/` | screenshots |

`index.html`, `es/`, `work/`, `style.css`, `theme.js` and `docs/` are **generated**. Editing
them by hand works until the next build overwrites it.

## How it is laid out

English sits at the root because the audience is European doctoral programmes. Spanish sits
under `/es/`. Every link is relative, so the site can be reviewed from a plain folder and not
only from the domain.

The note PDFs are built inside their own projects, which live next to this folder under
`Portafolio/`. `build.py` copies them on every run, so recompiling a note and rebuilding the
site is enough to publish it.

## Design

The palette is a flotation cell seen from above. The light theme is the froth, the pale layer
that floats and carries the value; the dark theme is the pulp underneath. That is what the
`froth / pulp` toggle means.

Each project is reported the way a plant reports a campaign: feed in, separation, concentrate
out, and an assay. The assay is the honest number, and it gets the same weight as the
headline, including where it is unflattering.

## Publishing

GitHub Pages serves this repository at the domain in `CNAME`. `.nojekyll` stops GitHub from
running Jekyll over it.
